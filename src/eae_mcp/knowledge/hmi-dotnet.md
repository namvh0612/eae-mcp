# .NET HMI (Canvas HMI)

Project `HMI/HMI.csproj`, framework `NxtControl.GuiFramework` (C#, WinForms-designer style).

| Document | Files | Base class / namespace |
|---|---|---|
| Canvas (screen) | `<Name>.cnv.cs/.Designer.cs/.resx`; `<Canvas>true</Canvas>` in csproj | `HMICanvas`, `HMI.Main.Canvases` |
| Resolution frame | `CanvasResolution_N.cnv.*`; listed in `CanvasesResolutionList.xml` | header, login, navigation, work area |
| CAT symbol | `<Cat>/<Cat>_<sym>.cnv.*` + `.cnv.xml` mapping | `HMISymbol`, `HMI.Main.Symbols.<Cat>` |
| CAT faceplate | `<Cat>/<Cat>_f<Name>.cnv.*` (no `.cnv.xml`); `IsFaceplate="true"` in `.cfg` | `HMIFaceplate`, `HMI.Main.Faceplates.<Cat>` |

- A **resolution** must exist before canvases can be created; canvases are listed under its `Topology`.
- On a canvas, a CAT symbol binds to an application instance with **`TagName = "<layer FB ID>"`**.
- Inside a symbol or faceplate, widgets bind with `TagName = "<HMI var>"` or a sub-CAT name/path.
- `InitializeComponent()` in `.Designer.cs` is generated by the designer; code-behind (`.cnv.cs`) holds custom logic.
